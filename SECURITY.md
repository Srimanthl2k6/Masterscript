# Security Policy

## Supported versions

Security fixes are applied to the latest published MasterScript desktop release. Users should keep automatic updates enabled and move to the newest version promptly.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/Srimanthl2k6/Masterscript/security/advisories/new) and include:

- the affected version and platform;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested mitigation.

The project will acknowledge a report within five business days, validate severity, coordinate a fix and release, and credit the reporter when requested and appropriate.

## Scope

In scope are the Tauri/Rust desktop boundary, local project persistence, imports and exports, LAN collaboration, updater trust, migration data, the website download surface, and release automation.

## Disclosure

Please allow a reasonable remediation window before public disclosure. Never include real screenplay content, updater signing material, or third-party personal data in a report.
