# Complete Screenwriting Software Feature Checklist
*Based on Final Draft, Celtx, Arc Studio Pro, WriterDuet, Fade In, Highland, Movie Magic Screenwriter, StudioBinder, and others*

---

## 1. CORE WRITING & FORMATTING

### Auto-Formatting
- [ ] Automatic industry-standard screenplay formatting (WGA/Hollywood standard)
- [ ] Tab/Return key element cycling (Scene Heading → Action → Character → Dialogue → Parenthetical)
- [ ] Auto-capitalization of scene headings and character names
- [ ] Automatic CONT'D on dialogue split across pages
- [ ] Automatic (MORE) / (CONT'D) on page breaks
- [ ] Smart margins and indentation per element type
- [ ] Courier 12pt font enforcement (industry standard)
- [ ] Automatic page break management with screenplay page-break rules (no widows/orphans for dialogue)
- [ ] Dual dialogue / simultaneous dialogue formatting (side-by-side)
- [ ] Correct line spacing per element type

### Script Elements
- [ ] Scene Heading / Slug Line (INT./EXT., location, time of day)
- [ ] Action / Description lines
- [ ] Character name (centered, above dialogue)
- [ ] Dialogue
- [ ] Parenthetical
- [ ] Transition (CUT TO:, FADE OUT., SMASH CUT TO:, etc.)
- [ ] Shot (CLOSE ON:, WIDE SHOT:, etc.)
- [ ] Superimposition / SUPER
- [ ] INTERCUT
- [ ] FLASHBACK / END FLASHBACK
- [ ] MONTAGE / END MONTAGE
- [ ] INSERT / BACK TO SCENE
- [ ] V.O. (Voice Over) extension
- [ ] O.S. (Off Screen) extension
- [ ] CONT'D extension
- [ ] Text / Title card formatting
- [ ] Custom element types (user-defined)

### SmartType / Auto-Complete
- [ ] Auto-complete character names (after first use)
- [ ] Auto-complete location names (INT./EXT. + location)
- [ ] Auto-complete time of day (DAY, NIGHT, MORNING, etc.)
- [ ] Auto-complete transitions
- [ ] Auto-complete shots
- [ ] Extension auto-complete (V.O., O.S., etc.)
- [ ] Rebuild character/location lists (to clean up removed characters)
- [ ] Global character rename (propagates throughout script)

### Text Editing
- [ ] Standard cut/copy/paste
- [ ] Find and Replace (with regex support in some)
- [ ] Find and Replace across entire script or selection
- [ ] Undo / Redo (multi-level)
- [ ] Select All
- [ ] Spell check
- [ ] Autocorrect
- [ ] Thesaurus / Synonym lookup
- [ ] Word count
- [ ] Page count
- [ ] Scene count
- [ ] Character count
- [ ] Estimated screen time calculation (roughly 1 min/page)
- [ ] Drag-and-drop text
- [ ] Multi-cursor editing (some platforms)

### Revision Mode (Production)

- [ ] Custom revision colors
- [ ] Revision color shown in printed/exported PDF
- [ ] Page locking (lock pages after shooting begins)

- [ ] OMITTED pages/scenes (retired numbers preserved)

- [ ] Reset revision marks
- [ ] Mark specific revisions only (not auto-track)
- [ ] Production draft export (with revision color header, date, draft name)
- [ ] Revision slug / title page tracking all previous revision colors

- [ ] Swap alternate content in/out
