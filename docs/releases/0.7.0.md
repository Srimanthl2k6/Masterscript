# MasterScript 0.7.0

- Enter splits the underlying screenplay block at the caret, replaces selected text and restores focus. Formatting, revisions, dual dialogue, locking, undo/redo and collaboration are preserved.
- A shared offline Scene Analysis engine detects silent cast and explicit production requirements. Breakdown opens with a first pass grouped by department; edits, confirmations, costs, notes and rejection records survive reanalysis and saving.
- Scene, Character, Location and Department reports share analysis. Dialogue statistics remain speech-specific. Scene cards and exports include production requirements.
- The website starts with the existing MasterScript logo and two choices: Use Web and Download. Downloads show every desktop/Linux format and standalone terminal binaries, using stable aliases.
- New `masterscript-tui` opens, edits, splits, navigates, searches and saves portable projects, with shared reports/breakdown editing, undo/redo, recovery autosaves and unsaved-work confirmation. Run `masterscript-tui --help` for shortcuts.
- Desktop updates check at startup and periodically, download in the background, and wait for idle conditions and successful project preservation before installing. Native Linux packages defer to the package manager.
- Linux packages include `/usr/bin/masterscript-tui`. Releases include a checksum-pinned `masterscript-bin` PKGBUILD and .SRCINFO validated through makepkg and pacman. AUR publication still requires maintainer SSH credentials.

Supported targets: Windows x64, macOS universal (Intel/Apple Silicon), Linux x64. Linux desktop formats: AppImage, deb, rpm and pkg.tar.zst. SHA-256 checksums are in `release-checksums.sha256`; desktop updates retain Tauri signature verification.

Analysis is a conservative English-rule first pass. Page counts are estimates. Schema-1 projects remain compatible; save a portable project copy before moving between devices.
