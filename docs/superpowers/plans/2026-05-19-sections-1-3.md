# MasterScript Sections 1-3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the first three roadmap sections: formatting engine, revision/production mode foundations, and story-development tools.

**Architecture:** Keep `ScriptProject.blocks` as the source of truth and extend the existing schema with backward-compatible optional/defaulted fields. Put durable behavior in focused library modules with Vitest coverage, then wire the active React workspace to those helpers without introducing another state store.

**Tech Stack:** React 19, TypeScript, Vite, Electron, Vitest, existing CSS, existing `pdf-lib`.
