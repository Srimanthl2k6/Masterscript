# Desktop parity matrix

Pass 1 freezes the Electron 0.1.13 behavior that the Tauri implementation must preserve. “Tauri owner” names the Pass 4 Rust command or frontend adapter that will assume responsibility; it does not indicate that the operation is implemented in the non-release Pass 1 shell.

## Runtime and project operations

| Capability | Current Electron path | Required behavior | Tauri owner | Pass 1 status |
| --- | --- | --- | --- | --- |
| Autosave | `project:autosave` | Persist the complete `.msproj.json` state | Rust atomic persistence | Contracted; Electron adapter active |
| Autosave recovery | `project:read-autosave` | Return a valid project or `null` without destructive recovery | Rust persistence | Contracted; Electron adapter active |
| Save As | `project:save-file` | Native picker, JSON serialization, remember returned path | Rust dialog + persistence | Contracted |
| Silent save to known path | `project:save-path` | Only `.msproj.json`; preserve current path workflow | Rust atomic persistence | Contracted |
| Open | `project:open-file` | Native picker and schema-compatible JSON load | Rust dialog + persistence | Contracted |
| Open recent path | `project:open-path` | Open a known local path and return failures safely | Rust persistence | Contracted |
| New project | React state | Stop collaboration, clear history, preserve schema defaults | React | Unchanged |
| Undo/redo | React history | Preserve 80 logical steps until Pass 6 changes representation | React | Unchanged |
| Revision snapshots | Project schema | Remain portable inside project files | React/Rust persistence | Unchanged |
| Browser fallback | Downloads/local storage | Keep web build functional | Web adapter | Active |

| Final Draft FDX | Yes | Yes | Electron text transfer + React adapter | Preserve XML content and warnings |

| Print preview | N/A | OS print | `window.print()` | WebView print parity or equivalent native path |
| Storyboard/sides/call-sheet PDFs | No | Yes | React generation | Preserve all report workflows |

## Keyboard and menu parity

| Input | Behavior |
| --- | --- |
| `Ctrl/Cmd+N` | New project |
| `Ctrl/Cmd+O` | Open project |
| `Ctrl/Cmd+S` | Save project |
| `Ctrl/Cmd+P` | Print preview |
| `Ctrl/Cmd+K` | Command palette |
| `Ctrl/Cmd+F` / `Ctrl/Cmd+H` | Find/Replace |
| `Escape` | Close the active File, Find/Replace, Snapshot, or command surface as currently implemented |
| `Tab` / `Shift+Tab` in a block | Cycle screenplay element type |
| `Enter` in a block | Insert the configured next screenplay block |
| `Shift+Enter` | New line inside the current block |
| `Backspace` in an empty block | Remove block and focus its neighbor |
| `Ctrl/Cmd+1..8` in continuous editor | Select screenplay element type |
| `Alt+Up/Down` | Cycle continuous-editor element type |
| Configured shortcuts | Preserve remappable scene/action/character/dialogue/parenthetical/transition/shot bindings |

The File menu must preserve Home, New, Open, all three imports, FDX/DOCX/PDF exports, Print Preview, Theme, Snapshots, Undo, and Redo.

## Acceptance rule

No Tauri implementation is parity-complete until every row is covered by automated or platform smoke tests. Unsupported methods in the Pass 1 Tauri adapter return an explicit error; they do not silently mutate data.
